# Sunbot Growth OS - GitHub Pages PWA

## Upload
Upload toàn bộ file/thư mục này lên thư mục gốc của GitHub repo.

Cần có:
- index.html
- manifest.webmanifest
- sw.js
- icons/

## Bật GitHub Pages
Settings → Pages → Deploy from branch → main → /root.

## Cài trên điện thoại
- iPhone: mở bằng Safari → Share → Add to Home Screen.
- Android: mở bằng Chrome → Install app / Add to Home screen.

## Ghi chú
Bản này dùng icon mới thanh lịch hơn, tone cam Sunbot, không dùng chữ dài trong icon để dễ nhìn trên điện thoại.
